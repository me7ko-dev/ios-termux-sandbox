# ios-termux-sandbox

Termux-style terminal for iOS, in-process only (no jailbreak, no fork/exec) —
built on [ios_system](https://github.com/holzschu/ios_system),
[SwiftTerm](https://github.com/migueldeicaza/SwiftTerm) and
[Citadel](https://github.com/orlandos-nl/Citadel).

Written on Windows without Xcode — **not yet built or run**. Start with
`Docs/STATUS.md` for what exists and what's verified, then `Docs/NEXT_STEPS.md`
for the plan.
